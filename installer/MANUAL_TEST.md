# 安裝程式人工測試清單

這份清單給在真實 Windows 電腦上測試安裝程式的人。自動化驗證已經涵蓋打包內容、體積與解壓後的執行，但「真正執行安裝程式」的幾項（Windows Sandbox 項目 2、3、5、8、9、10 與安裝時間）尚未執行，由這份清單補上。

## 開始前

- 測試機要乾淨：沒有 Python、沒有開發工具、沒有 Visual Studio、沒有 CUDA Toolkit。最好是全新的 Windows 10 或 11 虛擬機器或備用電腦。
- 要有網路。第一次啟動時精靈會從 GitHub 與 Hugging Face 下載模型和執行環境，總共數 GB。
- 安裝程式：`Video Subtitle Translator_0.1.0_x64-setup.exe`（由 `installer/build.ps1` 產生，約 83 MB）。
- 一支短的英文演講影片（1 到 3 分鐘即可），放在測試機上。
- 測試前先記下這些路徑，之後要用：
  - 安裝資料夾，預設 `%LOCALAPPDATA%\Video Subtitle Translator`
  - 使用者資料夾 `%LOCALAPPDATA%\video-subtitle-translator`（模型、執行環境、專案都在這裡）
- 每一項請記錄「通過」或「失敗」，失敗時附上截圖和你看到的訊息。

## 項目 9：不用系統管理員權限安裝

1. 用「標準使用者」帳號登入（不是系統管理員），或在系統管理員帳號下直接用滑鼠雙擊安裝程式。
2. 雙擊安裝程式，一路按下一步到完成。安裝程式不會問語言：它跟隨 Windows 的顯示語言（繁體中文、簡體中文、日文或英文），其他語言一律用英文。請確認畫面上的每一段文字都有內容，沒有空白的核取方塊或標題（例如「建立桌面捷徑」）。

預期結果：

- 全程沒有出現 UAC（使用者帳戶控制）要求輸入系統管理員密碼的視窗。
- 安裝完成後，程式位於 `%LOCALAPPDATA%\Video Subtitle Translator`，不在 `C:\Program Files`。
- 沒有出現 SmartScreen 以外的警告。SmartScreen 會因為安裝程式沒有程式碼簽章而警告，按「其他資訊」再按「仍要執行」即可，這是已知情況。

## 項目 2：安裝與開始功能表

1. 開始計時（見最後一節「記錄安裝時間」），執行安裝程式到出現「完成」。
2. 勾選「執行 Video Subtitle Translator」並按完成，或從開始功能表開啟。

預期結果：

- 開始功能表有「Video Subtitle Translator」，點下去能開啟程式。
- 桌面捷徑依安裝選項而定，有的話能開啟。
- 程式視窗出現，沒有彈出命令提示字元或錯誤對話框。
- 設定中的「已安裝的應用程式」有這個程式，大小與版本 0.1.0 合理。

## 項目 3：第一次啟動、精靈與處理

1. 第一次啟動會出現首次使用精靈。若電腦缺少 Microsoft Visual C++ 可轉散發套件，精靈會顯示一則紅色提示和連結。請點連結，安裝 `vc_redist.x64.exe`，再回精靈。
2. 看精靈對這台電腦的建議（顯示卡、記憶體、磁碟），照預設按「下載並開始」。
3. 等下載完成。中途按「取消下載」再按「繼續下載」一次，確認會從中斷處續傳。
4. 進入主畫面後，匯入準備好的英文影片，等它跑完語音辨識、翻譯與摘要。
5. 在播放畫面確認字幕顯示在影片下方，並開啟摘要。

預期結果：

- 精靈的文字是繁體中文，下載有進度，沒有看到英文的錯誤堆疊或 Python 字樣。
- 沒有安裝 Python、ffmpeg 或 CUDA Toolkit，處理仍能完成。
- 完成後有英文字幕、繁體中文字幕、雙語字幕和摘要，內容和影片相符。
- 沒有顯示卡的電腦會改用 CPU，速度較慢但能完成。
- 關閉程式後，工作管理員裡沒有留下 `vst-backend.exe`、`whisper-cli.exe`、`llama-server.exe` 等程序。

## 項目 10：路徑含中文與空格

1. 用中文使用者名稱的 Windows 帳號（例如 `王小明`）重做項目 2 和項目 3。沒有這種帳號時，在安裝程式的「選擇安裝位置」頁改成 `D:\測試 安裝\Video Subtitle Translator`（含中文和空格）。
2. 匯入一支放在含中文和空格資料夾裡的影片（例如 `D:\我的 影片\演講 一.mp4`）。

預期結果：

- 安裝、啟動、下載、處理與匯出都正常，沒有「找不到檔案」或亂碼的錯誤。
- 輸出的字幕檔和專案資料夾名稱正確顯示中文。

## 項目 8：舊版升級，保留資料

需要兩個版本的安裝程式。先用目前的 0.1.0 當舊版。再把 `app/src-tauri/tauri.conf.json` 的 `version` 改成 `0.1.1`，重新執行 `installer/build.ps1` 產生新版。

1. 安裝舊版，完成項目 3，讓使用者資料夾裡有模型和至少一個專案。
2. 不要先解除安裝。直接執行新版安裝程式，安裝到同一個位置。
3. 開啟程式。

預期結果：

- 安裝程式把它當成升級，沒有問「是否刪除資料」。
- 升級後精靈不再出現，已下載的模型與執行環境還在，舊專案還能打開。
- 設定頁顯示版本 0.1.1。
- 還沒有可用的線上更新網址。設定頁的「檢查更新」現在會回報連不上或需要登入，這是已知情況。更新網址會在原始碼公開到 GitHub 之後改到 GitHub Releases，那時再測「檢查更新」到「安裝並重新啟動」。

## 項目 5：解除安裝

做兩次，每次前先確認使用者資料夾裡有東西。

第一次，保留資料：

1. 從 Windows 設定的「已安裝的應用程式」解除安裝。
2. 解除安裝視窗有一個勾選框「同時刪除已下載的模型、執行環境與專案資料（不勾選則保留）」，只會問這一次。維持不勾選，完成解除安裝。

預期結果：安裝資料夾消失，開始功能表項目消失，`%LOCALAPPDATA%\video-subtitle-translator` 還在，模型和專案都沒少。重新安裝後精靈不再要求下載。

第二次，刪除資料：

1. 重新安裝，再解除安裝，這次勾選該勾選框。

預期結果：安裝資料夾和 `%LOCALAPPDATA%\video-subtitle-translator` 都消失。

另外確認：用 `/S` 靜默解除安裝，或升級時，都不會刪除使用者資料。

## 記錄安裝時間

目標是安裝在 60 秒內完成。

1. 備好碼錶或手機計時。在檔案總管中雙擊安裝程式後，等 SmartScreen 處理完，按到「安裝」的那一刻開始計時。
2. 在出現「完成」頁的那一刻停止。
3. 記下秒數、電腦型號、硬碟類型（SSD 或 HDD）和是否有防毒軟體即時掃描。第一次安裝後的第一次啟動也記一下，因為防毒軟體可能掃描新檔案而變慢。
4. 至少做三次（每次先完整解除安裝並刪除資料），取中間值。

## 回報

把每一項的結果、安裝時間和截圖交給負責人。失敗項目請附上 `%LOCALAPPDATA%\video-subtitle-translator` 底下的記錄檔（若有）。
