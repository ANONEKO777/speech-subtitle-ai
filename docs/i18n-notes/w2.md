# W2 notes: the first-run wizard and the models page

Branch `pr/P54-i18n-w2`, from `main` `ab9b41d`. The wizard, the models table, the delete dialog and the models folder card read the catalog. `zh-TW` is the old text, character for character. `en` is written by hand. `zh-CN` and `ja` are machine translations (marked in each file header, hidden from the picker).

## What was built

- **Catalog areas.** `wizard` (`wizard.*`) and `models` (`models.*`, `delete.*`, `storage.*`) in `app/src/i18n/catalog/<locale>/`. 133 keys in each of the four locales (54 wizard, 79 models). Plural keys: `models.summary`, `storage.confirm.body`, `storage.moving`, `storage.moved`.
- **Helpers.** `stateText`, `shaText`, `forceReasonError` (models page rules), `stateLabel`, `chipOrGpu`, `deviceLabel`, `cpuNotice` and `selfTestText` take a `Translate` with no default now. The W1 constants `PROFILE_NAME`, `PROFILE_BLURB` and `LOCAL_BUILD_*_TEXT` are deleted (their last caller moved). `tZhTW` stays the default only in the areas W3 still owns (`formatEta`, `sourceLabel`, `EXPERIMENTAL*`, `JOB_RUNNING`).
- **Wizard errors.** `WizardState.error` is `string | { assetId, message }` now. A failed download keeps the asset id and the backend message, and the screen words it (`wizard.jobFailed`), so a language switch re-words it. The self-test "no result" case is `error: null` on a `result` step with no test, worded by `wizard.noResult`. This changed one existing assertion in `flow.test.ts` (the state shape, not the text: `error: { assetId: "asset-1", message: "connection lost" }`).
- **Sizes and speeds** (`manage/format.ts`): `bytes`, `mib` and `speed` take the UI locale. The digits still come from `toFixed`, so zh-TW is identical, and only the decimal mark follows `Intl`. All four shipped languages use `.`, so nothing differs today. Callers in this area and `JobRow` and `HardwareSection` pass the locale; W3 callers use the default (zh-TW) and print the same text. There are no dates or ETAs on these screens.
- **Platform-aware example folder.** `storage.placeholder.win` or `.posix`, chosen by `isWindowsPath(storage.modelsDir)` (`manage/pathStyle.ts`). The backend reports the models folder of the machine it runs on, so the path style is the platform. No example shows until the settings have loaded. A Mac shows `/Volumes/Models/vst-models`. This is the one intended zh-TW pixel change (the Mac models page, placeholder text only). The W1b owner picks his own mechanism for the import box, the root can unify.
- **Guard.** `npm run check:strings` is 251 of 660 (388 after W1, 137 literals removed). No literal is left in `wizard/`, `models-page/`, `manage/`.
- **English wording.** Terms added to `docs/i18n-glossary.md` under "W2". The W1 `localBuild.noUpdate` English now says "Runtimes you build yourself" (it said "Programs", the glossary says runtime).

## Backend and shell text left as it comes (W4)

On the wizard: the profile load error (`fetchProfile` failure, `ApiError` message, English or Chinese as the backend wrote it), the failure message of a download job, the start error (`chooseProfile` or `downloadProfileAssets` failing), the self-test message, stage details and fallback reason (shown by `SelfTestPanel`), the `platforms.py` "unsupported platform" text, the `runtimes.py` "no ready-made program, build it here" text, license names and URLs from the registry, the GPU name and driver version, profile `label`.

On the models page: the update check `message`, every `UpdateItem.message` (a tooltip), the refusal message and blockers of a delete, verify, repair or download (`refusalOf`), `asset.blockers`, a job's `failure.message`, the repair `action` and `reason` words (`models.repaired*` shows them as the backend sends them), `asset.kind` (`asr`, `llm`, `whisper.cpp`), profile ids in "Used by" (`gpu-24gb`), the storage warnings (`setModelsDir`, `fetchMove`), the move `error`, the inventory and settings load errors, and `runtimes.py` "not removed, found elsewhere" text when it comes back as a refusal.

## Decisions

- The English for `wizard.recommended` is "We recommend the profile **24 GB GPU**. You can also choose from the other two below." The profile names carry commas ("Apple silicon, 32 GB or more"), so the name goes last.
- The partial state is "Incomplete" in English (the chip must stay one short word, "Partly downloaded" widened the Status column).
- `wizard.others.two` and `.three` are "two" and "three" (zh-TW keeps 兩 and 三). A count of one would read "the other 1 profiles". The backend lists three or four profiles, so one cannot happen today.
- Keys that repeat W1 wording on purpose: `wizard.recommendedTag` (zh 建議) next to `hw.recommendedTag`, `wizard.mayNotFit` (zh 這台電腦可能不夠用) next to `hw.mayNotFit` (zh 這台電腦可能不夠). The Chinese differs by one character, so they are not one key.

## Layout

All renders are Edge with a stubbed Tauri and backend (`.work/p54-shots/shots-w2.mjs`), not the Tauri window. Fixes, all scoped with `:root:lang(en)` in `app/src/manage.css`:

- The Visual C++ note is a flex row (icon-less `.note`), so its text, link and tail were three columns. In English it is one block (`.vc-note`). **In zh-TW the note is still three columns (it was before W2).** Fixing it would move zh-TW pixels, so it is left; a one-line follow-up (`display: block` for everyone) would fix it.
- The update line and the size label in the models table may wrap in English, and the Status chip is shorter, so the table fits at 1280 (it scrolled by 22 to 129 px before the fix).

**Known, not fixed.** At 960 the models table scrolls horizontally in both languages (zh-TW by 240 px, English by 258 px), because the Actions column starts about 700 px to the right of the page. This is today's zh-TW behavior (measured on `main`). A person has to scroll the table to reach the action buttons at the window's minimum width.
