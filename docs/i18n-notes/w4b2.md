# W4b part 2 notes: the remaining English backend and shell messages

Branch `pr/P62-i18n-w4b2`, from `372aad7` (head of `pr/P61-i18n-w4b`). Groups 7 to 14 of the table in `w4a.md`, and the gaps the part 1 verifier found in the guard. Every sentence below reaches the window with a code, and a window in Traditional Chinese words it from its catalog. The recipe is W4a's.

## What was built

- **Templates.** `backend/core/notices.py` has one block for each group, added after part 1's, so the part 1 fix round merges cleanly. The shell's templates are in `app/src-tauri/src/notice.rs`.
- **New fields.** `warnings_notices` on PUT `/api/storage` and PUT `/api/profile`. `error_notices` and `warnings_notices` on the move status. Nothing new is stored on disk, so an older build (`0d03565`) reads everything this build writes.
- **Window.** The storage card, the move status and the profile switch warnings are now a `Said`, worded at render. The player, the cue editor, the export menu and the import screen already read refusals through `said()`.
- **Shell.** `allow_video`, `pick_video`, `pick_videos`, `save_export`, `pick_folder`, `open_folder` and `open_url` reject with `notice::Said`. A sentence the shell writes has a code. An error from the system or from another library is `Said::plain`, which the window shows as it is. `folders.rs` produces only system errors, so it still returns `String`, and `lib.rs` wraps them.
- **Catalog.** The new keys are in `catalog/<locale>/notices2.ts`, generated from the sender's English and the reviewed wording. `notices.ts` is not touched.
- **Parameters.** A profile id is a `word` parameter (`noticeWord.gpu-24gb` and the others), so zh-TW shows the profile's name (24 GB 顯示卡). English keeps the id the backend sent.
- **Guard.** `tests/test_notices_guard.py` now reads the files of groups 7 to 14 (20 more files). It also treats `error`, `msg`, `warning` and `warnings` as message names, and the batch's `store.finish(...)` as a shown call. It found four more sentences the window can show, which now have codes (`manage.verifyRuntime`, `manage.nothingToUpdate`, `manage.verifyStopped`, `storage.cannotRead`). The sentences it found that the window never shows are in `NOT_SHOWN` with the reason.
- **refused().** `api/deps.refused` takes the sentences a refusal quotes, so "nothing to update for X: <update note>" sends the update note's notices too.
- **After P61.** `main` (`bf2223c`, W4b part 1 with its two fix rounds) is merged in. Both sides had added the `clauses` parameter kind; the branch keeps `word` beside it. `common.clauseSeparator` now lives only in `main`'s `shell.ts`. `notices.backend.json`, `notices2.ts` and the fixture were regenerated, not hand-merged, and a check found no catalog key in two area files and no code registered twice.
- **LLM settings save errors.** The checks a save or a connection test fails on now send a code (`settings.urlNotWeb`, `settings.urlNotHttps`, `settings.cloudNeedsHttps`, `settings.ollamaModelMissing`, `settings.cloudFieldsMissing`, `settings.cloudConsent`, `settings.keyRequired`, `settings.keyForNewAddress`). The consent sentence moved into `notices.py` as `CLOUD_CONSENT_TEXT`, so its refusal is one template and zh-TW words all of it. Both settings files are in the guard. The checks that only a hand-edited `settings.json` trips are in `NOT_SHOWN`, because `settings.fileNotUsed` quotes them as a detail.
- **The connection test and the API key.** `llm_check` hides the key with `backend.llm.client.redact` where the server's or the system's words come in (the redirect address, the HTTP reason, a connection error), with `cut=True` because either may have cut them off. Each notice is built from words that no longer hold the key, so its sentence and its parameters agree. `_redacted` is gone.
- **Repair words in English.** A repair note said "Repair: refetch". It now says "Repair: re-download", and "nothing to do" and "resume the download" for the other two actions. zh-TW was already worded.

| `move.otherContent` | "MoveError: X holds other content than Y; left alone" | "X holds other content than Y; left alone" | A class name from the code. |
| `move.wrongSize` | "OSError: X has the wrong size after the move" | "X has the wrong size after the move" | A class name from the code. |
| `switch.unknownMemory` | "This machine has unknown memory of memory; …" | "This machine's memory is unknown; …" | A broken sentence. |
| `cues.noTranslation` | "no zh-TW subtitles yet: …" | "no Traditional Chinese (Taiwan) subtitles yet: …" (the English window says "Traditional Chinese") | The language is now a `language` parameter, which names the language. |

A search of tests, e2e drivers and retry logic found nothing that matches on these sentences. `tests/test_manage.py` checks "not moved" in the unmoved warning, and that text is still there.
